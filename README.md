# Learn-Coding-by-Hand
Learning step by step process how to write code by hand
What you should remember while trying to learn how to write code by hand (AI as learning tool only)

Analyze the API: Use the original app or read its code to map out the API endpoints (e.g., POST /api/v1/tasks).Design the Database: Look at their database models and draw your own Entity-Relationship Diagram (ERD).Build the Backend First: Write the Express server, authentication (JWT/Cookies), and database queries from scratch. Test it with Postman.Build a Minimum Viable Frontend: Build the absolute core views in React (e.g., just the login and the main dashboard) before adding extra features.
